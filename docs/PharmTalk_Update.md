# 📱 팜톡(PharmTalk) — 스마트 약 서랍 기능 정의서

> **한 줄 요약:** 처방전 사진 한 장이면, 약 등록부터 금기 체크·복약 지도·가족 케어까지 한 번에.

---

## 1. AI 기반 초간편 약 등록 (Vision AI / OCR)

사용자의 입력 허들을 최소화하고, 정확한 의약품 DB를 구축하는 **핵심 진입점**.

### 1-1. 처방전 및 약 봉투 스캐너

- 사진 촬영 한 번으로 처방받은 약의 정보(약품명, 성분명, 복용량 등)를 AI가 즉시 인식하여 **자동 등록**
- 직접 약 이름을 검색·입력할 필요 없음 — 특히 처방약은 이름이 길고 어려워서 사진이 훨씬 편리
- OCR 인식 결과를 **표준 약품 코드(EDI 코드 등)**로 매핑하여 DB에 저장

### 1-2. DUR(의약품 안심 서비스) 자동 연동

- 약이 등록되는 즉시, 기존에 먹고 있던 약과 **병용 금기·중복 성분** 등을 백그라운드에서 자동 체크
- 심평원 개인 인증 불필요 — 공공데이터포털의 **'건강보험심사평가원_DUR품목정보 API'** 활용
- 사용자가 등록한 약품 코드끼리 자체 매칭하는 방식으로, **인증서 없이 DUR 규칙 적용**

#### DUR API 제공 데이터

| 항목 | 설명 |
|------|------|
| 병용금기 | 두 가지 이상의 약을 함께 복용 시 부작용·효과 변화가 발생하는 조합 |
| 임부금기 | 임산부 복용 시 태아 위험을 유발할 수 있는 약품 (1·2등급 분류) |
| 연령금기 | 소아·노인 등 특정 연령대에 투여 금지된 약품 |
| 효능군 중복 | 약 이름은 다르지만 같은 약효를 내는 약의 중복 복용 체크 |
| 용량/투여기간 주의 | 1일 최대 투여량 초과 또는 장기 복용 주의 약품 |
| 노인주의 | 65세 이상 고령자에게 부작용이 나타나기 쉬운 약품 |

#### DUR 자체 매칭 프로세스

```
[사용자] 처방전 사진 촬영
    ↓
[OCR] 약품명 인식 → 표준 약품 코드 변환
    ↓
[약 서랍 DB] 기존 약 코드 + 새 약 코드
    ↓
[DUR 스캐닝] 공공데이터 API로 금기 사항 크로스 체크
    ↓
[결과 알림] "A약과 B약은 병용금기입니다!"
```

> **핵심 포인트:** No 인증서, No 가입 장벽. 사진만 찍으면 끝.
> **성패의 열쇠:** OCR로 읽어낸 약품명을 얼마나 정확하게 표준 약품 코드로 매핑하느냐.

## 2. 목적별 스마트 서랍장 (약품 분류 관리)

복용 목적과 기간에 따라 UI/UX를 분리하여 직관적인 관리를 지원.

### ① 꾸준히 먹는 칸 (만성/장기 복용)

- 탈모약, 고혈압약, 당뇨약 등 **매일 규칙적으로** 먹어야 하는 약 관리
- 장기 복용 추적 및 리필 리마인더

### ② 처방약 칸 (단기 복용)

- 감기, 장염 등 병원 방문 후 **3~7일** 단위로 먹고 끝나는 일회성 약 관리
- 복용 기간 종료 시 자동으로 **'과거 복용 기록'으로 아카이빙**
- 1회성 복약 지도 제공 (약 5일 기준)

### ③ 영양제 칸

- 현재 복용 중인 건강기능식품 및 영양제 목록
- 처방약·다른 영양제와의 성분 충돌 체크

## 3. AI 기반 약 & 식음료 밀착 챗봇 (능동형 질의응답)

등록된 약을 기반으로 사용자가 **일상적인 언어로 직접 AI에게 질문**하는 방식. 단순 팝업이 아닌 **능동적 UX**로 설계.

#### 사용 시나리오

| 사용자 질문 | AI 응답 |
|------------|---------|
| "나 오늘 저녁에 회식이라 소주 마실 건데, 아까 먹은 약 괜찮아?" | "등록하신 처방약에 항생제(OOO)가 있네요! 알코올과 만나면 간 독성 위험이 커져요. 오늘은 절대 금주하셔야 합니다!" |
| "점심 먹고 바로 아이스 라떼 마셔도 돼?" | "드시고 계신 빈혈약(철분제)은 커피의 타닌 성분 때문에 흡수가 안 돼요. 최소 2시간 뒤에 드세요!" |
| "자몽 먹어도 돼?" | "고혈압약과 자몽은 약 혈중 농도를 급격히 높일 수 있어요. 자몽·자몽주스 피하세요!" |
| "항생제 먹고 있는데 우유랑 같이 먹어도 돼?" | "유제품의 칼슘이 항생제 흡수를 방해해요. 2시간 이상 간격을 두세요!" |

#### 기술 구현 (RAG 방식)

- 약사 노하우 + 식약처 데이터로 **약-음식 상호작용 DB** 구축
- LLM(Claude 등) 연결 시 사용자의 **약 서랍 리스트 + 상호작용 DB**를 컨텍스트로 주입
- 환각(Hallucination) 없이 정확하고 친절한 답변 생성

> **핵심 포인트:** 기계적 알림은 무시하기 쉽지만, "내가 당장 먹고 싶은 걸 AI에게 물어보고 답을 얻는 건 완전히 다른 차원의 UX."

## 4. 복약 순응도 및 가족 케어 (Family Link)

사용자 본인뿐만 아니라 **2030 세대가 부모님의 건강을 챙길 수 있도록** 확장.

### 4-1. 스마트 알람 및 스케줄러

- 등록된 약의 복용 주기에 맞춰 **푸시 알람** 제공
- 복용 체크(Check-in) 시스템으로 **스케줄 달성률 트래킹**
- 사용자가 체크 기능 ON/OFF 선택 가능

### 4-2. 가족 약 서랍 연동

- 가족 계정을 연동하여 "오늘 부모님 혈압약 드셨는지", "아이 감기약 먹었는지" **원격 확인**
- 보호자 알림 기능 포함

### 4-3. 대리 AI 질문 (가족 교차 케어)

- 자녀가 부모님의 약 서랍 데이터 기반으로 **AI에게 대신 질문**
- 예: "우리 엄마 관절염 약 드시고 계신데, 홍삼 선물 같이 드셔도 돼?"
- 부모님이 직접 타이핑하기 어려울 때, 자녀가 **건강 코디네이터 역할** 수행

### 4-4. "이거 엄마 사드려도 돼?" — 영양제 충돌/과잉 필터링

- 자녀가 부모님께 영양제를 사드리기 전, 제품명/성분 검색
- 부모님의 약 서랍(처방약 + 기존 영양제) 데이터와 **교차 검증**
- 결과 예시:
  - "어머니 이미 삐콤씨 드시고 있어서 비타민 B군은 과잉이에요. 차라리 칼슘/마그네슘을 사드리세요."
  - "드시고 계신 고혈압약과 이 영양제는 상호작용 위험이 있습니다."

> **핵심 포인트:** 약사만 알 수 있는 중복 복용·성분 충돌 문제를 데이터 매칭으로 해결. 자녀 입장에서 돈 낭비를 막고 부모님 건강도 지키는 확실한 유인책.

### 4-5. 보호자용 '카톡 1초 요약 브리핑' (가입 장벽 제거)

- 부모님이 처방전 사진을 찍어 약 서랍에 등록하는 순간, **보호자용 요약본 자동 생성**
- 카카오톡으로 바로 전송 가능 — 온 가족을 앱에 억지로 가입시킬 필요 없음

#### 카톡 브리핑 예시

```
[엄마의 약국 다녀온 날]

1. 항생제 (위장장애 주의, 식후 바로 드시게 하세요)
2. 진통제 (아플 때만)

※ 우유랑 같이 드시지 않게 챙겨주세요.
```

> **핵심 포인트:** 한국인에게 가장 익숙한 카톡을 통해 약사의 복약 지도를 자녀에게 직행.

## 5. 영양제 코디 및 상담 서비스

데이터 기반 추천과 약사 상담을 결합하여 **수익 모델(BM)과 리텐션**을 끌어올리는 기능.

### 5-1. 데이터 기반 영양제 코디

- 사용자가 등록한 처방약 + 기존 영양제를 분석
- 부족한 영양소를 채워주거나, **피해야 할 영양제를 필터링**하여 맞춤 추천

### 5-2. 약사 1:1 상담 연결

- 약 서랍 데이터를 기반으로 전문 약사와 **심도 있는 건강 상담** 진행
- 내가 먹고 있는 약을 등록해 놓으면 상담 맥락이 바로 공유됨

## 전체 서비스 플로우 요약

```
📸 사진 촬영 (처방전 / 약 봉투)
  ↓
🔍 AI OCR 인식 → 약품명 추출 → 표준 코드 매핑
  ↓
💊 약 서랍 자동 등록 (꾸준히 / 처방약 / 영양제 분류)
  ↓
⚠️ DUR 자동 체크 (병용금기 · 중복 · 연령금기 등)
  ↓
🤖 AI 챗봇 상시 질의 ("소주 마셔도 돼?" "커피 괜찮아?" + 부작용·주의사항 안내)
  ↓
👨‍👩‍👧‍👦 가족 연동 (복용 확인 · 대리 질문 · 영양제 충돌 체크 · 카톡 브리핑)
  ↓
💡 영양제 코디 + 약사 상담
```
